# AuriTerm

A colorful, command driven terminal environment for Termux.

Created by Auri

# Features

AuriBot, a programmed assistant
, ColorArt, colorful ASCII art
, Demon Database, fictional entries
, Corruption Engine, visual glitch effects
, Diagnostics, system information
, Settings, themes and preferences
, Command Center, terminal commands

# Installation

pkg install git python -y
git clone https://github.com/AuriCuki1/AuriTerm.git
cd AuriTerm


# Launch

python main.py
